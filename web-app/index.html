Use Secrets in Your Code

Export your vault as .enc and use it from any language. The vault file is universal — just need the crypto libraries.

CLI (any OS)
# Get a secret printf '%s\n' "YOUR_PASSWORD" | vault-cli get vault.enc RECORD_ID # Pipe into any program DATABASE_URL=$(vault-cli get vault.enc db-url) curl -H "Authorization: Bearer $(vault-cli get vault.enc api-token)" https://api.example.com
Python
from vault_client import Vault vault = Vault.open("vault.enc") vault.unlock("master-password") # Get a secret api_key = vault.get("aabbccddeeff00112233445566778899") print(api_key) # List all record IDs for record_id in vault.list(): print(record_id)
Node.js / TypeScript
import { Vault } from 'vault-client-js'; const vault = new Vault('./vault.enc'); await vault.unlock('master-password'); // Get a secret const apiKey = await vault.get('aabbccddeeff00112233445566778899'); console.log(apiKey); // Use in Next.js API route export async function GET() { const token = await vault.get('github-token'); return Response.json({ token }); }
Go
package main import "github.com/your-org/vault-go" func main() { vault, _ := vault.Open("vault.enc") vault.Unlock("master-password") // Get a secret apiKey, _ := vault.Get("aabbccddeeff00112233445566778899") fmt.Println(apiKey) }
Java / Kotlin
import com.yourorg.vault.*; Vault vault = Vault.open("vault.enc"); vault.unlock("master-password"); // Get a secret String apiKey = vault.get("aabbccddeeff00112233445566778899"); System.out.println(apiKey);
Rust (embed directly)
use vault_core::Vault; use vault_db::VaultFile; let mut vf = VaultFile::open("vault.enc")?; vf.unlock("master-password")?; let secret = vf.get_secret(record_id)?; // secret is Vec — your API key, password, whatever

How It Works

Encryption: XChaCha20-Poly1305 (RFC 8439) — each secret gets its own unique encryption key

Key Derivation: Argon2id (RFC 9106) — your master password is turned into a cryptographic key

Key Hierarchy: Password → Argon2id → KEK → unwraps VEK → HKDF → per-record DEK → encrypts secret

Integrity: HMAC-SHA256 detects any tampering with the vault file

Format: Single .enc file — 256-byte header + encrypted records. Portable across all platforms and languages.

Export / Import

Export creates a .enc file you can copy to any machine. Import reads it back. The file is useless without the master password.
